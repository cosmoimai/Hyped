# Bundled typography

Static font URLs and expected SHA-256 digests come from the font metadata in `google_fonts` 8.2.1 (the runtime package has been removed). Each downloaded file was checked against its expected length and SHA-256.

License sources: [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope), [Outfit](https://github.com/google/fonts/tree/main/ofl/outfit).
