Widget Setup Guide

iOS Setup
1

Touch and hold an empty area on your home screen until apps jiggle.

2

Tap the (+) Add button in the top corner.

3

Search ‘Hyped!’ and select either the Small or Medium size.

4

Tap the placed widget to customize which countdown event is showcased.
